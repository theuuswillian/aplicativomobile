# Logos das instituições

Os arquivos SVG desta pasta são usados localmente pelo seletor e pela lista de contas do GranaViva. Cada banco possui seu próprio arquivo, sem sprite compartilhado ou requisição a serviços de terceiros em tempo de execução.

- Bancos e instituições brasileiras: diretório público `logos-bancos-br`, que identifica logos publicados no diretório do Open Finance Brasil ou nos sites oficiais das instituições.
- Binance: Simple Icons, usada apenas para identificar a exchange.
- As marcas e logotipos pertencem às respectivas instituições. O uso no GranaViva é exclusivamente identificativo, para o usuário reconhecer a instituição vinculada à própria conta.

Fontes:
- https://github.com/rzmt/logos-bancos-br
- https://github.com/simple-icons/simple-icons
